CanSat Project

Title: Atmospheric Data Acquisition and Telemetry CanSat

Description
A low-cost CanSat developed using ESP32 to measure atmospheric parameters and transmit the data wirelessly to a ground station.

Features
- Temperature Monitoring
- Humidity Monitoring
- Pressure Measurement
- Altitude Calculation
- Air Quality Monitoring
- Wireless Communication using NRF24L01
- OLED Display at Ground Station

Hardware
- ESP32
- DHT22
- BMP180
- ADXL345
- LED
- NRF24L01
- OLED Display

Software
- Arduino IDE
- GitHub
- C/C++
